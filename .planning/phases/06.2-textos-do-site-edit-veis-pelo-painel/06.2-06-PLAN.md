# 06.2-06 — Migração, testes e guia

## Task 1 — Migração e tipos
- Banco de dev no estado das migrações atuais; `pnpm payload migrate:create textos_do_site` (padrão de
  nome e snapshot `.json` dos anteriores; registrar em `src/migrations/index.ts`). Conferir que a
  migração só CRIA as tabelas `textos_*` (nada de drop/alter em tabela existente).
- `pnpm generate:types`, `pnpm generate:importmap`.

## Task 2 — Testes novos
- `tests/int/textos.int.test.ts`: anônimo lê `textos-inicio`; assinante (overrideAccess false) não
  consegue `updateGlobal`; equipe salva um valor e `mesclarTextos` devolve o valor; string vazia →
  padrão. Seguir os helpers de `tests/helpers/seed.ts`.
- `tests/e2e/textos.spec.ts`: equipe (REST, helper existente de login staff) troca o título "Próximas
  festas"/campo correspondente de `textos-inicio` e um rótulo do menu em `textos-geral`; a home mostra os
  novos textos; volta o campo a vazio e o texto original reaparece. `afterAll` limpa.

## Task 3 — Verificação completa
`pnpm typecheck`, `pnpm lint`, `pnpm test:unit`, `pnpm test:int`, `pnpm test:e2e` (todo o conjunto).
Falha em e2e de texto = padrão copiado errado → corrigir o `padrao`, nunca o teste.
`pnpm build` (sem banco no build: `getTextos` cai nos padrões sem quebrar).

## Task 4 — Guia
`docs/painel/GUIA-DA-EQUIPE.md`: seção "Textos do site" (onde fica no menu, uma área por página, seções,
salvar publica na hora, apagar volta ao original, variáveis entre chaves como `{plano}`, o que não está
ali: erros, e-mails, textos das páginas da coleção Páginas e dados de Contato).
