# 06.2-01 — Infra dos textos editáveis + área "geral"

Leia antes: `06.2-CONTEXT.md` (decisões T-01..T-11 e a tabela de áreas). Código e comentários seguem o
estilo do repositório (comentários curtos em inglês no código, textos de interface em português).

## Task 1 — Registro, mescla e leitura

1. `src/lib/textos/tipos.ts` (puro, sem `server-only`):
   ```ts
   export type CampoTexto = { rotulo: string; padrao: string; secao?: string; longo?: boolean; ajuda?: string }
   export type AreaTextos = { slug: string; rotulo: string; descricao: string; campos: Record<string, CampoTexto> }
   export function definirArea<const C extends Record<string, CampoTexto>>(area: {
     slug: string; rotulo: string; descricao: string; campos: C
   }) { return area }
   export type TextosDaArea<A extends { campos: Record<string, CampoTexto> }> = { [K in keyof A['campos']]: string }
   ```
   `longo` omitido → automático: textarea quando `padrao.length > 90` ou contém `\n`.
2. `src/lib/textos/areas/<area>.ts` para as 16 áreas da tabela do CONTEXT (`geral`, `inicio`, `festas`,
   `espaco`, `modelos`, `institucional`, `contato`, `assine`, `conta`, `areaAssinante`, `classisex`,
   `meusAnuncios`, `enviarConto`, `contos`, `dicasHot`, `mensagens`), cada um
   `export const <area> = definirArea({ slug: 'textos-…', rotulo: '…', descricao: '…', campos: {} })`
   com slug/rótulo da tabela. Só `geral` recebe campos neste plano. **Os planos 02-05 editam só os
   arquivos das próprias áreas** — por isso todos os arquivos e o `index.ts` nascem aqui.
   `src/lib/textos/areas/index.ts`: `export const AREAS = { geral, inicio, … } as const`,
   `export type AreaKey = keyof typeof AREAS`, `export type Textos<K extends AreaKey> = TextosDaArea<(typeof AREAS)[K]>`.
3. `src/lib/textos/mesclar.ts` (puro): `padroesDaArea(area)`, `mesclarTextos(area, doc)` (string não
   vazia após trim → valor salvo, senão `padrao`; ignora chaves extras e não-strings), `preencher(texto, vars)`
   (troca `{nome}` por `String(vars.nome)`; chave ausente fica como está).
4. `src/lib/textos/queries.ts` (`import 'server-only'`): `getTextos<K extends AreaKey>(area: K): Promise<Textos<K>>`
   usando `cached(fetch, ['textos', area], () => ['textos:' + area, 'textos'])` sobre
   `payload.findGlobal({ slug: AREAS[area].slug, depth: 0 })`. Área sem campos → só padrões, sem
   consulta. `try/catch` em volta de tudo: erro → `console.error` curto + `padroesDaArea`.
   Documentar as tags novas no comentário de `src/lib/cache/expire.ts`.
5. `src/lib/textos/TextosGeraisProvider.tsx` (`'use client'`): contexto com `Textos<'geral'>`;
   `useTextosGerais()` devolve o contexto ou, fora do provider, os padrões da área `geral`.
