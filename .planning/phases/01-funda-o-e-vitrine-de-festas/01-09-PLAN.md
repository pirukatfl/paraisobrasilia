## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → /api/parties (REST) | Anonymous reads and write attempts |
| staff session → admin mutations | Authenticated writes trigger cache invalidation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-25 | Information disclosure | Draft parties via REST/Local API | mitigate | access.read returns `{ _status: { equals: 'published' } }` for anonymous; queries filter `_status`; int test with overrideAccess false |
| T-01-26 | Elevation of privilege | Anonymous create/update/delete on parties, media, users | mitigate | access requires `req.user`; int test asserts Forbidden for all three collections |
| T-01-27 | Denial of service | Revalidation storms | accept | Only authenticated staff mutations trigger revalidation; volume is a few edits per week |
| T-01-28 | Repudiation | Who published/unpublished | mitigate | Payload versions (`maxPerDoc: 20`) keep history with timestamps; full staff audit log is PAINEL-08 in Phase 3 |
