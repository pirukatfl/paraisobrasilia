# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Scope: public site (age gate, home with upcoming party flyers, party page, 404/error) and the staff-facing labels of the Payload admin for parties. All user-facing copy is pt-BR.

Sources: CONTEXT.md D-01..D-07 (brand, mood, party fields, no WhatsApp CTA per party, no address), RESEARCH.md (Next 16 + Tailwind 4, Payload admin, age-gate pattern), logo pixel sampling of `brand/logo-original.webp`.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, chip inner vertical padding |
| sm | 8px | Gap inside price rows, between date and time lines |
| md | 16px | Page side gutter on mobile, card inner padding, gap between flyer cards on mobile |
| lg | 24px | Gap between flyer cards ≥ 640px, section heading to content |
| xl | 32px | Page side gutter ≥ 1024px, gap between party page sections |
| 2xl | 48px | Header to first section, section breaks on home |
| 3xl | 64px | Footer top margin, age-gate dialog vertical padding on desktop |

Exceptions: none in the spacing scale. Touch targets (buttons, card links, header logo link, skip link) declare a minimum size `min-height: 44px; min-width: 44px` (WCAG 2.5.5) — this is a box size, not a spacing token; buttons use 8px vertical / 24px horizontal padding and are centered within the 44px minimum height.

Layout:
- Max content width 1200px, centered.
- Party page text column max width 680px.
- Breakpoints (Tailwind defaults): `sm` 640px, `lg` 1024px.

## Typography

| Role | Size | Weight | Line Height | Font / Treatment |
|------|------|--------|-------------|------------------|
| Body | 16px | 400 | 1.5 | Inter; party details, age-gate text, empty-state body |
| Label | 14px | 600 | 1.4 | Inter; date/time line, price labels, section eyebrow labels (uppercase, letter-spacing 0.08em), footer, buttons |
| Heading | 24px | 400 | 1.2 | Josefin Sans uppercase, letter-spacing 0.06em; section titles ("Valores", "Atrações"), card titles, age-gate heading |
| Display | 36px | 600 | 1.1 | Josefin Sans uppercase, letter-spacing 0.04em; home H1 "Próximas festas", party title H1 |

Exactly 4 sizes (14 / 16 / 24 / 36) and 2 weights (400 / 600). Display stays 36px on all breakpoints (long party titles wrap; `text-wrap: balance`). Numerals in prices use `font-variant-numeric: tabular-nums`.

## Color

Values sampled from `brand/logo-original.webp` (D-02 "extrair os valores exatos"): background #010101, arch/"PARAÍSO" orange #E48424–#E28026, "BRASÍLIA" red #A82A1E, ♀ symbols deep red #961E12, ♂ symbols gold #DEB436. Contrast ratios measured against Dominant.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0B0908` (`--color-bg`) | Page background, age-gate backdrop base (at 92% opacity), header/footer |
| Secondary (30%) | `#17120F` (`--color-surface`) with border `#2A221D` (`--color-line`) | Flyer card body, price list rows, age-gate dialog panel, info blocks on party page |
| Text primary | `#F4EDE4` (`--color-text`, 17.1:1) | Body and headings |
| Text muted | `#B8ADA2` (`--color-muted`, 9.0:1) | Secondary text, footer, attraction kind labels |
| Accent (10%) | `#E8821E` (`--color-accent`, 7.2:1; brand orange) | See reserved list |
| Accent — informational (gold) | `#DEB436` (`--color-gold`, 10.1:1; brand gold) | Semantic role only: party date/time line on cards and party page, price values. Justification: D-04 asks for orange/gold highlights; gold marks "when / how much" information, orange marks "what to click". Never used on buttons or links. |
| Brand red (decorative only) | `#A82A1E` (`--color-brand-red`, 2.85:1 — NOT for text) | Only inside the logo image and the 2px top border gradient of the header (`linear-gradient(90deg, #E8821E, #A82A1E)`) |
| Destructive / error | `#E5533D` (`--color-danger`, 5.3:1) | Error-state text and icon on the public error page; "Esta festa já aconteceu" badge border/text |

Accent (orange) reserved for:
1. Primary button background ("Tenho 18 anos ou mais — Entrar", "Ver próximas festas", "Tentar de novo") with text `#0B0908` (7.2:1)
2. Keyboard focus ring on every focusable element (`outline: 2px solid #E8821E; outline-offset: 2px`)
3. Flyer card hover/focus border (1px → accent)
4. Text links inside party details (underlined) and the "Ver todas as festas" back link
5. The 2px header top border gradient (shared with brand red)

No other element uses orange. No neon/glow effects, no gradients on surfaces except the header line (D-04).

## Screens and Visual Hierarchy

### S1 — Age gate overlay (INST-04)
- Full-viewport fixed overlay, backdrop `#0B0908` at 92% opacity + `backdrop-filter: blur(8px)`; page HTML is rendered underneath (never removed).
- Centered dialog panel (`--color-surface`, 1px `--color-line` border, radius 12px, max width 440px, padding 32px mobile / 64px desktop vertical, 24px horizontal mobile / 48px desktop).
- **Focal point:** logo (header logo asset, 160px wide) above the heading; then heading, body, primary button (full width), secondary text button below.
- `role="dialog"`, `aria-modal="true"`, `aria-labelledby` heading, focus moves to the primary button on open, Tab cycles within the dialog, Escape does nothing (decision must be explicit), body scroll locked while open.
- Hidden instantly (no animation) for returning visitors via `html[data-age-ok]` set by the inline head script; first confirmation fades out over 150ms (`prefers-reduced-motion: reduce` → no fade).

### S2 — Home `/` (FEST-01, FEST-04)
- Header: logo left (height 40px mobile / 48px desktop, links to `/`, `aria-label="Paraíso Brasília — página inicial"`), 2px gradient top line. No nav menu in Phase 1 (other pages arrive in Phase 2).
- Intro: eyebrow label "Casa de festas liberais em Brasília" (Label, muted) + H1 "Próximas festas" (Display).
- **Focal point:** the first (soonest) flyer — it is the LCP image (`priority`), and on ≥ 1024px it spans 2 columns × 2 rows in the grid when there are ≥ 3 parties.
- Grid: 1 column < 640px; 2 columns 640–1023px; 3 columns ≥ 1024px; gap 16px / 24px.
- Flyer card (whole card is one link to `/festas/{slug}`, `aria-label="Ver detalhes da festa {título}"`): flyer image in its own aspect ratio (`1/1` for square, `4/5` for portrait; `object-fit: cover`, radius 8px top), below it a 16px-padded body with date/time line (Label, gold, calendar icon + "Sáb, 24 out · 23h") and title (Heading, 2-line clamp). Hover/focus: border becomes accent, image scales 1.02 over 200ms (disabled with reduced motion).
- Sorted by `startsAt` ascending; only published parties with `endsAt > now`.
- Footer: muted Label text "© {ano atual} Paraíso Brasília · Proibido para menores de 18 anos". Year computed at render, no hard-coded range.

### S3 — Party page `/festas/[slug]` (FEST-02, FEST-03)
- Mobile: single column — flyer (full width, own aspect ratio), then text column. ≥ 1024px: two columns, flyer left (sticky, 5/12 width), text right (7/12, max 680px).
- **Focal point:** the flyer; second: H1 title (Display).
- Order of content: back link "← Ver todas as festas" (accent) · date/time block (gold Label: "Sábado, 24 de outubro" / "A partir das 23h") · H1 title · summary (Body, muted) · section "Valores" (list rows: label left, value right in gold, tabular nums; hidden if no prices) · section "Dress code" (Body; hidden if empty) · section "Atrações" (list "DJ · Nome", kind in muted Label; hidden if empty) · section "Sobre a festa" (rich text: paragraphs, bold, italic, lists, links only; hidden if empty).
- No address, no map, no WhatsApp CTA on this page (D-06, D-07).
- Past party (endsAt ≤ now, reached by direct link): badge "Esta festa já aconteceu" (danger color text + 1px border, Label) above the title and primary button "Ver próximas festas" at the end; page still renders for shared links.
- Section headings use Heading style with a 24px gap below.

### S4 — Not found (`not-found.tsx`) and S5 — Error (`error.tsx`)
- Centered block, max width 480px, 48px top margin: Heading + Body + primary button. Error variant shows the message in danger color.

### Admin (Payload) — PAINEL-01
- Language `pt` default, dark theme, brand logo on login screen and nav icon.
- Collection "Festas": list columns Título, Data e hora, Status. Field order and labels exactly as in the Copywriting table below. Flyer upload shows crop/focal point.

## Interaction & Accessibility Contract

- Every interactive element reachable by keyboard with the accent focus ring; skip link "Pular para o conteúdo" (Label, visible on focus) as first element.
- `html lang="pt-BR"`.
- All flyer images have `alt` (from media `alt`, fallback "Flyer da festa {título}"); decorative SVG icons `aria-hidden`.
- Motion: only the 150ms gate fade and 200ms card scale; both disabled under `prefers-reduced-motion: reduce`.
- No layout shift: flyer containers reserve space via `aspect-ratio`; fonts via `next/font` with `adjustFontFallback`.
- Age gate cookie: `pb_age_ok=1; Max-Age=2592000; Path=/; SameSite=Lax; Secure` (30 days).
- Performance budget (supports MIG-04 later): home LCP < 2.5s on mid-range mobile 4G; only the age-gate island ships client JS on public pages.
