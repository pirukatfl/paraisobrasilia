## Shared Patterns

### Server-only data access
**Source:** RESEARCH.md Architectural Responsibility Map + ARCHITECTURE.md Pattern 1
**Apply to:** every page under `src/app/(frontend)`
Pages never call `fetch('/api/...')` and never import collection configs; they call functions in `src/lib/parties/queries.ts`, which use `getPayload({ config })` and return plain DTOs (`PartyCardDTO`, `PartyDetailDTO`). Components receive DTOs only. Mark query modules with `import 'server-only'`.

### Design tokens
**Source:** UI-SPEC.md Color/Typography/Spacing
**Apply to:** all components
Tailwind 4 `@theme` variables in `src/app/(frontend)/globals.css` (`--color-bg`, `--color-surface`, `--color-line`, `--color-text`, `--color-muted`, `--color-accent`, `--color-gold`, `--color-brand-red`, `--color-danger`, `--font-display`, `--font-body`) — utilities `bg-bg`, `bg-surface`, `border-line`, `text-text`, `text-muted`, `bg-accent`, `text-gold`, `text-danger`, `font-display`, `font-body`. No hex literals in components (`grep -rn '#[0-9A-Fa-f]\{6\}' src/components` returns nothing).

### Time zone
**Source:** RESEARCH.md Pitfall 2
**Apply to:** any code that formats or compares party dates
Use `src/lib/format/date.ts` (`America/Sao_Paulo`) and `src/lib/parties/visibility.ts`; never call `toLocaleString` without `timeZone`.
