## Trust Boundaries

| Boundary | Description |

| app container → db container | Internal Docker network only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-29 | Information disclosure | Postgres on VPS | mitigate | No `ports:` on db; ufw allows only 22/80/443; smoke test asserts 5432 closed |
| T-01-30 | Information disclosure | Secrets in repo or image (DB, PAYLOAD_SECRET) | mitigate | .env.staging only on server; .dockerignore excludes .env*; build args carry only public NEXT_PUBLIC_* values; B2 key scoped to one bucket |
| T-01-31 | Spoofing | Traffic interception | mitigate | Caddy automatic HTTPS + HSTS; Payload cookies secure in non-development |
| T-01-32 | Elevation of privilege | Container running as root | mitigate | runner stage `USER node` |
| T-01-33 | Spoofing | SSH brute force | mitigate | Key-only access shared by the client; password auth disabled is recommended in the runbook (client's server policy) |
| T-01-34 | Information disclosure | Staging indexed | mitigate | SITE_ENV=staging → noindex header + robots (01-08); smoke asserts it |
| T-01-35 | Denial of service | Data loss on staging | accept | Staging holds test parties only; automated backups are Phase 7 scope |
</threat_model>
