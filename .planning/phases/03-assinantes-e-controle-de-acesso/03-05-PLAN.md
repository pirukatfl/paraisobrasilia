## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → /nova-senha | token-bearing URL |
| subscriber session → trocarSenha | password change of the logged-in account |
| staff → WhatsApp | link delivery outside the system |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-11 | Spoofing | leaked reset link | mitigate | single use, 48 h, a new link invalidates the previous one, sessions revoked on reset, no third-party resources on the page, Referrer-Policy |
| T-03-03 | Tampering | public forgot-password to overwrite staff link | mitigate | guard from 03-01 (context flag); regression int test |
| T-03-04 | Spoofing | session hijack after password change | mitigate | password update revokes other sessions (Payload); e2e second-context logout |
| T-03-10 | Information disclosure | token/password in audit or logs | mitigate | audit summary without token; int test scans rows; no console logging |
| T-03-23 | Elevation of privilege | subscriber changes someone else's password | mitigate | action uses the id from the session (requireAssinante), never from the form |
</threat_model>
