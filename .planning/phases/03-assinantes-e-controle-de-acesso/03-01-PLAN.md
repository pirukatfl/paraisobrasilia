<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| subscriber session → /api/* | a logged-in non-staff principal reaches every REST/GraphQL endpoint |
| internet → /api/assinantes/* | login, first-register, forgot-password endpoints exist for every auth collection |
| internet → /entrar | credential submission, `?next=` parameter |
| proxies/CDN → members HTML | caching or indexing of personal pages |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of privilege | all access functions (`Boolean(req.user)`) | mitigate | src/access/roles.ts keyed on `req.user.collection === 'users'`; access-roles.int regression |
| T-03-02 | Spoofing / EoP | POST /api/assinantes, /first-register | mitigate | access.create isStaff + beforeOperation guard (`trustedCreate` context only for seeds/migrations); int test |
| T-03-03 | Information disclosure / tampering | POST /api/assinantes/forgot-password | mitigate | beforeOperation guard requires `staffPasswordLink` context |
| T-03-04 | Spoofing | /entrar brute force | mitigate | maxLoginAttempts 5, lockTime 10 min, generic message; int test |
| T-03-05 | Information disclosure | members pages cached/indexed | mitigate | dynamic rendering (private, no-store), X-Robots-Tag noindex in all envs, robots disallow, metadata noindex; e2e header asserts |
| T-03-07 | Information disclosure | subscriber reads other subscribers / staffNotes | mitigate | read self only; field access staff-only; int test |
| T-03-08 | Tampering | open redirect via `next` | mitigate | safeNext allowlist; unit test |
| T-03-12 | Tampering (CSRF) | cookie-authenticated requests from other origins | mitigate | SameSite=Lax, Payload `csrf` allowlist, Next server-action origin check |
| T-03-14 | Denial of service | attacker locks a known account | accept | 10-minute lock, staff can unlock in admin; low value target |
| T-03-17 | Elevation of privilege | subscriber opens /admin | mitigate | admin.user = users (canAccessAdmin false), `access.admin: () => false` on assinantes; checked again in 03-06 sweep |
</threat_model>
