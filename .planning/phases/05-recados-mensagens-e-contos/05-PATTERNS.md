## Conventions observed (carry over)
- Comments in English, UI/admin copy in Portuguese; threat IDs in code comments (`// T-05-xx`).
- Collection slugs in English (`contos` is the exception: it is the product name and the URL; keep `contos`), admin labels Portuguese; admin groups 'Contos', 'Recados e mensagens'.
- Members URLs in Portuguese: `/area-do-assinante/recados`, `/area-do-assinante/mensagens`, `/area-do-assinante/mensagens/nova`, `/area-do-assinante/mensagens/{id}`, `/area-do-assinante/contos/{slug}`; public `/recados`, `/contos`, `/contos/{slug}`.
- Public queries: published/visible only, bounded, cached with tags, DTO out. Subscriber reads: never cached, DAL-guarded. Nothing private reaches a client component except what it renders.
- `'.js'` suffix on `next/cache.js` imports in modules loaded by plain Node (hooks reachable from the config, the import CLI).
- New gated collections join the phase leak matrix (05-11, pattern of 03-06/04-09).
