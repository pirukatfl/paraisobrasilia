<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| subscriber → messaging service (via actions, 05-09) | ids and text from the browser |
| anyone incl. staff → /api/conversations, /api/messages | REST surface |
| account deletion → messages | personal data lifetime |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Information disclosure | thread IDOR | mitigate | participant check in getThread/sendMessage/markRead; int tests with a third subscriber |
| T-05-06 | Information disclosure / Spoofing | expired or anonymous messaging | mitigate | canSend requires both active; pages guarded (05-09) |
| T-05-08 | Denial of service | message/conversation spam | mitigate | 20 new conversations and 200 messages per São Paulo day; int tests |
| T-05-09 | Information disclosure (LGPD) | staff or REST reading messages | mitigate | access `() => false` on every operation, admin hidden; int tests with staff principal |
| T-05-10 | Spoofing / Information disclosure | account enumeration via recipient ids | mitigate | recipient derived only from a visible ad/recado or an existing conversation |
| T-05-12 | Information disclosure (LGPD) | messages after account deletion | mitigate | Assinantes cascade deletes conversations and messages |
</threat_model>
