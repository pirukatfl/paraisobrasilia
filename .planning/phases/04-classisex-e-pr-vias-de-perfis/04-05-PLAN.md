## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → /area-do-assinante/midia/* | direct links to originals |
| internet → /api/media/file/*, /api/videos/file/*, /api/ad-media/file/* | Payload's static file routes |
| subscriber upload bytes → disk | untrusted files with device metadata |
| container → host disk | data must survive restarts (volume) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02 | Information disclosure | originals via direct URL | mitigate | private volume; ad-media read staff-only; route handler canViewMedia per request; e2e anonymous/expired/other |
| T-04-03 | Information disclosure | traversal into private files through public file routes | mitigate | private dir outside MEDIA_DIR and public/ (assert at config load); leak test in 04-09 |
| T-04-05 | Information disclosure | expired subscriber keeps opening media | mitigate | entitlement computed on every request in the route |
| T-04-06 | Information disclosure | EXIF/GPS, MP4 location | mitigate | sharp re-encode (no withMetadata); scrubMp4Metadata; int tests |
| T-04-08 | Information disclosure | CDN/proxy caching of private bytes | mitigate | Cache-Control private + Vary Cookie; never next/image |
| T-04-09 | Denial of service | huge files | mitigate | per-type caps, Payload 100 MB limit, Caddy 110 MB request cap |
| T-04-10 | Tampering | disguised files (HTML/SVG as image) | mitigate | mime allowlist + sharp decode + mp4 parse; served with fixed types and nosniff |
| T-04-11 | Information disclosure | reversing the blurred preview | mitigate | 16 px intermediate; stdev test |
| T-04-16 | Availability / data loss | compose not refreshed on the VPS | mitigate | uploads refused in production without PRIVATE_MEDIA_DIR; runbook + client step in 04-10 |
