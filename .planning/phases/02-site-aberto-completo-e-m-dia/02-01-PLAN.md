## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | anonymous update of contact global (redirect WhatsApp to a scammer) | mitigate | access.update isStaff; int test asserts Forbidden |
| T-02-02 | Tampering | malformed values breaking links (e.g. javascript: in fields) | mitigate | regex validation for whatsapp/instagram/CEP, numeric ranges for lat/lng; URLs built only by contact.ts with fixed hosts |
| T-02-03 | Information disclosure | referrer/tracking to third parties | mitigate | iframe referrerPolicy no-referrer, outbound links rel noopener noreferrer; no Google embed |
| T-02-04a | Spoofing | old Facebook/Instagram links pointing to removed/hijacked accounts | mitigate | no hard-coded social URLs; Instagram only from the global; grep acceptance check |
