## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-16 | Information disclosure | legacy-login.ts | mitigate | never logs password, hash or token; audit summary has no secret; int test scans audit rows |
| T-06-17 | Elevation of privilege | forgotPassword via `legacyPasswordUpgrade` | mitigate | flag only in req.context (not settable over HTTP); set only after verifyWpPassword succeeded; int test with flag in REST body |

| T-06-21 | Tampering (CSRF) | /entrar | mitigate | src/proxy.ts unchanged (`git diff --quiet`); e2e foreign-Origin POST → 403; cookies unchanged (Lax, httpOnly) |
