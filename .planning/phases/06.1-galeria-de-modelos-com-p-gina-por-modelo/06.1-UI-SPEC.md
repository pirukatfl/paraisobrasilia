## Screens

### S11' — Modelos `/modelos` (MIDIA-06; replaces S11)
- Route/nav/footer/sitemap visibility unchanged: only when ≥ 1 model is published; otherwise 404 (S4).
- Eyebrow "Modelos da casa" · H1 "Modelos" · intro "As modelos que animam as noites do Paraíso." (unchanged).
- Grid: 2 columns < 1024px, 4 columns ≥ 1024px (unchanged).
- Card = one link to `/modelos/{slug}` with accessible name **"Ver fotos de {nome}"** wrapping: cover (first photo, `card` derivative, aspect 4/5, cover, radius 8px, border `--color-line`, hover/focus border accent), then the artistic name (Label), then the count line (Label, muted) shown only when there is more than one photo or at least one video: "{n} fotos", "{n} fotos · 1 vídeo", "{n} fotos · {m} vídeos", "1 foto · {m} vídeo(s)".
- First 2 covers `loading="eager"`, the rest lazy (unchanged rule).
- No lightbox on this page anymore. No contact, no other fields.

### S12 — Página da modelo `/modelos/{slug}` (MIDIA-07)
- Exists only while the model is published; otherwise the 404 page (S4). Age gate applies like every open page (no login).
- Layout (single column, max content width as other open pages):
  1. Eyebrow link **"Modelos"** → `/modelos`.
  2. H1 = artistic name (Display), `id="titulo-modelo"`; `<article aria-labelledby="titulo-modelo">`.
  3. Count line (Label, muted): "{n} fotos" / "1 foto", plus " · 1 vídeo" / " · {m} vídeos" when there are videos.
  4. Description (Body, muted, ≤ 680px, line breaks kept) — omitted when empty.
  5. Gallery grid = S9 unchanged (2 / 3 / 4 columns, square tiles, video tiles with "Vídeo" badge + play icon). **Order: videos first (0–3, panel order), then photos (1–30, panel order).** Tiles open the S10 lightbox ("Galeria de fotos", counter "{i} de {total}", swipe/arrows, video plays only on its slide). Without JavaScript each tile links to the large image / MP4 (inherited).
  6. Text link **"Ver todas as modelos"** → `/modelos` (Label, muted, underline, accent on hover).
- Photo alt: staff alt text; fallback "{nome} — modelo do Paraíso Brasília". Lightbox label under the slide: photo alt / video title.
- Nothing else: no parties, no measurements, no contact, no share buttons, no comments.

### Share preview / SEO (S12)
- `<title>` "{nome} · Paraíso Brasília"; meta description = description (trimmed) or "{nome}, modelo do Paraíso Brasília: fotos e vídeos."; canonical `/modelos/{slug}`; `og:image` = the cover (`og` 1200×630 derivative when present).

### Admin (Payload) — `models` (PAINEL-09)

| Element | Copy |
|---------|------|
| Collection description | Nome artístico, descrição curta, de 1 a 30 fotos (a primeira é a capa) e até 3 vídeos. Sem nudez explícita e sem contato: esta galeria é aberta ao público. |
| Field `name` label | Nome artístico |
| Field `slug` label / help | Endereço / Endereço da página: /modelos/…  Se ficar vazio, é criado a partir do nome. Mudar o endereço quebra links já compartilhados. |
| Field `description` label / help | Descrição curta / Até 300 caracteres. Aparece na página da modelo e nas prévias do Google e do WhatsApp. Sem telefone, WhatsApp, e-mail, @ ou links. |
| Field `photos` help | De 1 a 30 fotos. A primeira é a capa: arraste para mudar a ordem. |
| Field `videos` label / help | Vídeos / Até 3 vídeos (MP4). Envie antes em Arquivos → Vídeos, com a imagem de capa. |
| Error: too many photos | Cada modelo pode ter no máximo 30 fotos. |
| Error: no photo | Envie pelo menos 1 foto. |
| Error: too many videos | Cada modelo pode ter no máximo 3 vídeos. |
| Error: slug format | Use só letras minúsculas, números e hífens. |
| Error: slug taken | Já existe uma modelo com este endereço. |
| Error: contact in name/description | Tire telefone, WhatsApp, e-mail, @ e links: esta página é aberta ao público. |
| List columns | Nome artístico, Endereço, Fotos, Autorização (date or "—"), Status |
