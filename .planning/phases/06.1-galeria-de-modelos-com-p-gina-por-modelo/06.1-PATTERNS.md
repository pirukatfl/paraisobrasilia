## Pattern Assignments

### `src/collections/Models.ts` (collection, CRUD + hooks)

**Analog:** `src/collections/Dicas.ts`

**Slug default + pt errors** (Dicas.ts `prepare`, lines 21–55):
```typescript
const fail = (req, path: string, message: string): never => {
  throw new ValidationError({ collection: 'dicas', errors: [{ path, message }], req }, req.t)
}
const prepare: CollectionBeforeValidateHook = async ({ data, originalDoc, operation, req }) => {
  if (operation === 'create' && !data.slug && typeof data.title === 'string' && data.title) data.slug = slugify(data.title)
  ...
  const clash = await withRequestState(req, () => req.payload.find({ collection: 'dicas', where: { and: [{ slug: { equals: slug } }, ...(originalDoc?.id ? [{ id: { not_equals: originalDoc.id } }] : [])] }, limit: 1, depth: 0, pagination: false, overrideAccess: true, draft: true, req }))
  if (clash.docs.length) fail(req, 'slug', DICA_MESSAGES.slugTaken)
}
```
Differences for models: generate also on update when `data.slug ?? originalDoc?.slug` is empty; an auto-generated slug is suffixed (`-2`, `-3`…) instead of failing; only a staff-typed slug fails with `slugTaken`.

**Access** (Dicas.ts lines 80–87): add `readVersions: isStaff` next to the existing `read: staffOrPublished`.

**Array validate with pt message** (current Models.ts `photos`):
```typescript
maxRows: 3, // MAX_MODEL_PHOTOS
validate: (value: unknown) => {
  const count = Array.isArray(value) ? value.length : 0
  if (count > MAX_MODEL_PHOTOS) return 'Cada modelo pode ter no máximo 3 fotos.'
  if (count < 1) return 'Envie pelo menos 1 foto.'
  return true
},
```
