# Phase 06.1 Plan 02: Videos on the model page Summary

**Staff attach up to 3 videos (Arquivos → Vídeos) to a model; the model page shows them first as poster tiles that play in the shared lightbox, counts read "2 fotos · 1 vídeo", and a 30-photo + 3-video page transfers 293 KB on a phone.**

## Accomplishments
- `models.videos` (array, maxRows 3, `video` upload to `videos`, required) with `Cada modelo pode ter no máximo 3 vídeos.`; models without videos are unchanged.
- Migration `models_videos` is additive only (two CREATE TABLE + FKs + indexes; `down()` drops those two tables).
- `queries.ts`: `toVideoItem()` extracted from the space DTO and reused; `toModelPageDTO` items = videos then photos; `videoCount` in card and page DTOs.
- `Videos.ts` afterChange/afterDelete expire the `space` and `models` tags.
- Tests: int (limit 4/3/0, DTO order and counts, no `imageAuthorization` for anonymous), e2e card/page counts + lightbox video playback, mobile budget.
